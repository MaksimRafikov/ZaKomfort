# Обновление каталога (короткий регламент)

## 1) Подготовить новый кейс

Запусти:

```powershell
python scripts/scaffold-case.py --title "ЖК Новый Объект" --address "Уфа, ..."
```

Скрипт:
- создаст `assets/<case-id>/`;
- выведет готовый шаблон объекта для вставки в `js/data.js`.

## 2) Перенести медиа в production-папку

- Исходники держим в `inbox/<slug>/`.
- На сайт ссылаемся только на `assets/<case-id>/...`.
- Минимум: `after-1.png`, `expert-overview.mp4` (если `hasVideo: true`).

## 3) Добавить объект в `js/data.js`

- Вставь шаблон из скрипта в массив `CASES`.
- Проверь `id`, `cover`, `gallery`, `video.fileUrl`, `video.poster`.

## 4) Проверить целостность

```powershell
python scripts/validate-cases.py
```

Ожидаемый результат: `VALIDATION_OK`.

## 5) Быстрый чек перед публикацией

- Карточка открывается в каталоге и на странице кейса.
- Нет битых картинок/видео.
- CTA и ссылки корректны.
- Фильтры не ломаются для нового кейса.
