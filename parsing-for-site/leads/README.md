# Лиды: поставщики фитнес-индустрии Москвы (покупатели базы)

Список потенциальных **покупателей** базы клубов — поставщиков и сервисов для
фитнес-индустрии Москвы/МО (вариант продаж №1: прямые продажи).

- `suppliers_moscow.csv` / `suppliers_moscow.xlsx` — **113 компаний** в 34 нишах:
  тренажёры, бассейны (оборудование/химия), CRM/ПО, СКУД/турникеты, спортпит,
  маркетинг, напольные покрытия, клининг, вентиляция, форма, мебель/шкафчики,
  кроссфит, проектирование/строительство, SPA/массаж, зеркала, вода/кулеры,
  пластиковые карты, бокс/единоборства, маты/татами, солярии, вендинг, EMS,
  сауны/хамам, освещение.
- Поля: `Компания`, `Категория (что продаём)`, `Сайт`, `Телефон`, `E-mail`, `Город`.
- Все 113 — с телефоном, 105 — с e-mail.

## Как использовать
1. Берёте компанию → пишете/звоните в отдел продаж.
2. Оффер: «готовая база спортивных объектов РФ под ваши холодные продажи» +
   демо-ссылка (`../data/demo_sample.csv`).
3. Под нишу можно выгрузить срез базы (например, «только бассейны» — для
   поставщиков химии/оборудования бассейнов).

## Источник
Контакты собраны автоматически с официальных сайтов компаний (скрипт
`find_suppliers.py`: обход главной и страниц контактов, извлечение телефона и
e-mail). Это публичные корпоративные контакты.

```bash
python3 find_suppliers.py --workers 12   # пересобрать список
```
