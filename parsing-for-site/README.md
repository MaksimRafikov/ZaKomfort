# Парсинг для сайта — каталог клубов sportgyms.ru

Парсер каталога фитнес-клубов, бассейнов и спортцентров с сайта
[sportgyms.ru](https://sportgyms.ru/). Собирает по каждому клубу:

| Поле | Источник на странице |
|------|----------------------|
| Название клуба | `<h1>` / `og:title` |
| Город | блок `.ciCities` |
| Адрес | блок `.ciAdress` |
| Телефон | блок `.ciPhone` |
| Режим работы | блок `.ciWorkTime` |
| Ссылки на сайт или соц. сети | блок `.ciNC` |

Результат — `data/sportgyms_clubs.csv` (UTF-8 с BOM, открывается в Excel) и
`data/sportgyms_clubs.xlsx`.

## Почему через веб-архив

Живой сайт защищён анти-бот сервисом (`protect274`), который **жёстко блокирует
запросы с дата-центровых IP**: вместо страницы отдаётся «Sorry, your request has
been denied», а капча («Я не робот» / похожая картинка / похожий цвет) с таких
адресов не проходит даже при абсолютно верном ответе (проверка идёт по репутации
IP). Это подтверждено экспериментально (headless-браузер + автоматическое решение
цветовой капчи с точным совпадением — отказ).

Поэтому данные берутся из публичного **веб-архива (Wayback Machine)**, где те же
страницы доступны без анти-бота. Для каждого клуба используется самый свежий
снимок `200 OK` (в основном 2025–2026 гг.).

> Для запуска с обычного (резидентного) IP можно добавить прямой режим: логика
> парсинга HTML (`parse_club`) переиспользуется как есть.

## Установка

```bash
pip install -r scraper/requirements.txt
```

## Запуск

```bash
cd scraper

# 1) скачать индекс снимков Wayback (CDX), ~17 МБ, несколько минут
python3 parse_sportgyms.py --build-cdx

# 2) спарсить весь каталог (~9.5 тыс. клубов) в CSV + XLSX
python3 parse_sportgyms.py

# варианты:
python3 parse_sportgyms.py --limit 50      # быстрый прогон на 50 клубах
python3 parse_sportgyms.py --city kazan     # только один город (слаг из URL)
python3 parse_sportgyms.py --workers 8      # больше потоков
python3 parse_sportgyms.py --xlsx-only      # пересобрать XLSX из готового CSV
```

Прогон **докачиваемый**: при повторном запуске уже собранные клубы (по полю
`URL источника`) пропускаются.

## Как устроено сопоставление со снимками

1. Список карточек берётся из `sitemap.xml` (шаблон `/<город>/<id>-<slug>.html`).
2. Из CDX-индекса строятся два индекса самого свежего снимка `200`:
   - по точному URL;
   - по паре `(город, числовой id)` — устойчиво к смене `slug` (переименования).
3. Для каждой карточки берётся снимок по URL, иначе — по `(город, id)`.
4. Архивная страница скачивается «как есть» (суффикс `id_`, без перезаписи ссылок)
   и парсится.
