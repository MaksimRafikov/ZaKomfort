# База фитнес-клубов, бассейнов и спорткомплексов России — 6 632 объекта

Готовый структурированный справочник спортивных объектов РФ для отделов продаж,
маркетинга и аналитики. Источник — открытый каталог sportgyms.ru.

| Тип объекта (фитнес-клуб / бассейн / спорткомплекс / студия …) | 100% |

Дополнительно: `URL источника` и `Дата снимка` (для проверки актуальности).

## Форматы поставки

- `data/sportgyms_clubs.csv` — единый файл (UTF-8 с BOM, открывается в Excel).
- `data/sportgyms_clubs.xlsx` — оформленный Excel: фильтры, закреплённая шапка,
  отдельные листы-сводки «Города», «Типы», «Сети».
- `data/by_city.zip` — та же база, разбитая на **отдельный файл по каждому городу**.
- `data/demo_sample.csv` — **бесплатный демо-образец** (60 строк из 22 городов).

## Кому полезна

- Поставщики для фитнес-индустрии: оборудование, химия для бассейнов, спортпит,
  клининг, СКУД/турникеты, вендинг, сервис тренажёров.
- IT/SaaS: CRM и ПО для клубов, онлайн-расписание, эквайринг.
- Маркетинговые и SMM-агентства, ищущие клиентов в нише.
- Франшизы, инвесторы, девелоперы — анализ рынка и конкуренции по городам.

## Честно об источнике и ограничениях

- Данные **публичные** (сам sportgyms.ru, также пересекаются с 2ГИС/Яндекс.Картами).
  Это удобная готовая выжимка, а не закрытый эксклюзив.
- **Актуальность:** часть данных взята из веб-архива; у каждой строки указана
  `Дата снимка` (в основном 2025–2026 гг.). Перед обзвоном рекомендуется выборочная
  проверка телефонов.
- **Полнота:** в каталоге-источнике ~9 573 карточки; собрано 6 632. Остальные
  ~2 900 в открытом виде сейчас недоступны (сайт закрыт анти-бот защитой,
  блокирующей автоматический доступ) — их можно добрать через резидентный прокси
  по отдельному запросу.
- **Юридически:** это справочник организаций (корпоративные контакты). Массовый
  обзвон/рассылка регулируется законом «О рекламе» и 152-ФЗ — ответственность
  за использование лежит на покупателе.
