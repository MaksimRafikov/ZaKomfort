# New Project

Самостоятельный стартовый шаблон лендинга на чистом HTML, CSS и JavaScript. Живёт в репозитории отдельно от каталога «За Комфорт» и ни на что в нём не ссылается.

## Возможности

- Без сборки и зависимостей — открывается прямо в браузере.
- Адаптивная вёрстка (375 / 768 / 1024 / 1440 px).
- Светлая и тёмная тема с сохранением выбора в `localStorage`.
- Доступность: семантическая разметка, видимый фокус, `prefers-reduced-motion`.
- Простая форма с валидацией email.

## Запуск

```bash
# из корня репозитория
python3 -m http.server 8080
# затем откройте http://localhost:8080/new-project/
```

Или просто откройте `new-project/index.html` в браузере.

## Структура

```
new-project/
├── index.html      # разметка страницы
├── css/styles.css  # стили и темы
├── js/main.js      # переключение темы и валидация формы
└── README.md
```

## Настройка

- Цвета и шрифты — CSS-переменные в начале `css/styles.css`.
- Тексты и секции — `index.html`.
- Логика формы — `js/main.js` (сейчас имитирует отправку; подключите свой backend в обработчике `submit`).
